01 ↗

Give it a key.

A name, a session, a little JSON. Store a value with a key that makes sense to you.

SET user:42 '{"name":"Ada"}'
02 ↗

Skip the long way.

Ask for the same key and read straight from memory. That's the idea behind a cache hit.

GET user:42
03 ↗

Let the old stuff go.

Add an expiration. When time is up, the value steps aside and makes room for what's next.

SET session:42 "active" EX 60
